# 드로어블

[코드북 홈](../README.md) · [전체 작성 상태](../CODEBOOK_PLAN.md)

이미지 배경, 상태 선택, Shape 및 중첩 Drawable을 별도 XML 리소스로 구성하는 분류다. 담당 기능은 6개다. 아래 한 행을 한 독립 예제 단위로 삼으며, 구현에 필요한 기본 UI만 포함한다. 공통적인 화면 연결 코드는 의존 코드로 설명하고 새 기능 구현으로 중복 집계하지 않는다.

| 기능 ID | 기능명 | PPT 출처 | 독립 예제 단위 |
|---|---|---|---|
| F065 | 정적 배경 이미지·색 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.50-54 | 정적 배경 이미지·색만 구현하는 별도 예제 예정 |
| F066 | 상태 셀렉터 드로어블 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.55-60 | 상태 셀렉터 드로어블만 구현하는 별도 예제 예정 |
| F067 | 기본 Shape 드로어블 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.61-66 | 기본 Shape 드로어블만 구현하는 별도 예제 예정 |
| F068 | 그라데이션 배경 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.67-69 | 그라데이션 배경만 구현하는 별도 예제 예정 |
| F069 | 여러 Shape 중첩과 테두리 버튼 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.70-74 | 여러 Shape 중첩과 테두리 버튼만 구현하는 별도 예제 예정 |
| F070 | 버튼 배경 틴트 간섭 제거 | `(Part2)Chapter02_레이아웃익히기.pdf` PDF p.84-85; `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.64, 73 | 버튼 배경 틴트 간섭 제거만 구현하는 별도 예제 예정 |

각 예제는 필요한 전체 Java/XML, Drawable 및 실행 방법을 함께 제공한다. 시험 조건이 바뀌면 수정할 ID·변수·메서드·속성을 한국어 주석과 예제 README에 적는다. PPT 외 코드는 `[추가 코드]`, SDK 대응 변경은 `[호환성 수정]`으로 이유를 표시한다. 실제 작성 여부와 검증 상태는 [원장](../CODEBOOK_PLAN.md)에서 관리한다.
