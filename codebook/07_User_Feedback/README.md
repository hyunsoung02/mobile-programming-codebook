# 사용자 알림

[코드북 홈](../README.md) · [전체 작성 상태](../CODEBOOK_PLAN.md)

Toast, Snackbar, AlertDialog를 각각 독립된 알림 기능으로 학습하는 분류다. 담당 기능은 4개다. 아래 한 행을 한 독립 예제 단위로 삼으며, 구현에 필요한 기본 UI만 포함한다. 공통적인 화면 연결 코드는 의존 코드로 설명하고 새 기능 구현으로 중복 집계하지 않는다.

| 기능 ID | 기능명 | PPT 출처 | 독립 예제 단위 |
|---|---|---|---|
| F008 | 간단한 토스트 메시지 | `(Part1)Chapter03_첫번째앱만들기.pdf` PDF p.37-40; `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.105-106, 138-139 | 간단한 토스트 메시지만 구현하는 별도 예제 예정 |
| F080 | 토스트 위치·여백·사용자 모양 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.140-147 | 토스트 위치·여백·사용자 모양만 구현하는 별도 예제 예정 |
| F081 | Snackbar | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.148-149 | Snackbar만 구현하는 별도 예제 예정 |
| F082 | AlertDialog | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.150-158 | AlertDialog만 구현하는 별도 예제 예정 |

각 예제는 필요한 전체 Java/XML, Drawable 및 실행 방법을 함께 제공한다. 시험 조건이 바뀌면 수정할 ID·변수·메서드·속성을 한국어 주석과 예제 README에 적는다. PPT 외 코드는 `[추가 코드]`, SDK 대응 변경은 `[호환성 수정]`으로 이유를 표시한다. 실제 작성 여부와 검증 상태는 [원장](../CODEBOOK_PLAN.md)에서 관리한다.
