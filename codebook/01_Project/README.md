# 프로젝트와 화면 연결

[코드북 홈](../README.md) · [전체 작성 상태](../CODEBOOK_PLAN.md)

앱의 시작점, 파일 위치와 시작 액티비티 등록을 찾는 분류다. 담당 기능은 3개다. 아래 한 행을 한 독립 예제 단위로 삼으며, 구현에 필요한 기본 UI만 포함한다. 공통적인 화면 연결 코드는 의존 코드로 설명하고 새 기능 구현으로 중복 집계하지 않는다.

| 기능 ID | 기능명 | PPT 출처 | 독립 예제 단위 |
|---|---|---|---|
| F001 | 액티비티 시작과 화면 설정 | `(Part1)Chapter03_첫번째앱만들기.pdf` PDF p.20-24, 54 | [MainActivity의 onCreate와 XML 화면 연결](F001_MainActivity_XML/README.md) · 작성 완료 · 미검증 |
| F011 | 소스·레이아웃·드로어블 위치 구분 | `(Part2)Chapter01_안드로이드스튜디오와친숙해지기.pdf` PDF p.104 | 소스·레이아웃·드로어블 위치 구분만 구현하는 별도 예제 예정 |
| F012 | 시작 액티비티 등록 | `(Part2)Chapter02_레이아웃익히기.pdf` PDF p.32, 38-39 | 시작 액티비티 등록만 구현하는 별도 예제 예정 |

각 예제는 필요한 전체 Java/XML, Drawable 및 실행 방법을 함께 제공한다. 시험 조건이 바뀌면 수정할 ID·변수·메서드·속성을 한국어 주석과 예제 README에 적는다. PPT 외 코드는 `[추가 코드]`, SDK 대응 변경은 `[호환성 수정]`으로 이유를 표시한다. 실제 작성 여부와 검증 상태는 [원장](../CODEBOOK_PLAN.md)에서 관리한다.
