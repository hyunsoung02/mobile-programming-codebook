# 방향 전환과 액티비티 생명주기

[코드북 홈](../README.md) · [전체 작성 상태](../CODEBOOK_PLAN.md)

방향별 리소스, 액티비티 재생성, 상태 복원과 방향 설정을 분리하는 분류다. 담당 기능은 5개다. 아래 한 행을 한 독립 예제 단위로 삼으며, 구현에 필요한 기본 UI만 포함한다. 공통적인 화면 연결 코드는 의존 코드로 설명하고 새 기능 구현으로 중복 집계하지 않는다.

| 기능 ID | 기능명 | PPT 출처 | 독립 예제 단위 |
|---|---|---|---|
| F075 | 방향별 레이아웃 리소스 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.107-115 | 방향별 레이아웃 리소스만 구현하는 별도 예제 예정 |
| F076 | 방향 전환 생명주기 확인 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.111-115 | 방향 전환 생명주기 확인만 구현하는 별도 예제 예정 |
| F077 | 인스턴스 상태 저장·복원 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.116-126 | 인스턴스 상태 저장·복원만 구현하는 별도 예제 예정 |
| F078 | 재생성 없이 방향 변경 수신 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.127-135 | 재생성 없이 방향 변경 수신만 구현하는 별도 예제 예정 |
| F079 | 화면 방향 고정 | `(Part2)Chapter03_기본위젯과드로어블사용하기.pdf` PDF p.136-137 | 화면 방향 고정만 구현하는 별도 예제 예정 |

각 예제는 필요한 전체 Java/XML, Drawable 및 실행 방법을 함께 제공한다. 시험 조건이 바뀌면 수정할 ID·변수·메서드·속성을 한국어 주석과 예제 README에 적는다. PPT 외 코드는 `[추가 코드]`, SDK 대응 변경은 `[호환성 수정]`으로 이유를 표시한다. 실제 작성 여부와 검증 상태는 [원장](../CODEBOOK_PLAN.md)에서 관리한다.

F077은 자료의 `outString`을 실제 `Bundle.putString`으로 고쳐야 하는 항목이다. F078의 `screenSize`·`onConfigurationChanged` 표기는 원본 코드 이미지와 일치시키고 정정 내역을 설명한다. 자세한 원문 오탈자는 [기능 인덱스](../../FEATURE_INDEX.md)를 따른다.
